# Convertly · 单位换算工具站(俗,大流量词)

~500 单位对 × 9 类目(长度/重量/温度/体积/面积/速度/时间/数据/压力/能量)+ **数值页**(165 cm to inches 等 200 个高频真实值)。全部系数为国际精确定义,纯客户端计算。698 静态页。

三个不掺假的事(站群纪律):

- 换算系数是国际精确定义(SI + 国际码制),公式印在每页;温度用标准变换式;-40°C=-40°F 交叉点有测试锚点。
- KB(1000)与 KiB(1024)分开建页,绝不混淆。
- 免 Cookie 纯浏览器计算——隐私即卖点。

## 站点结构

| 路径 | 内容 | SEO 角色 |
|---|---|---|
| `/convert/[from]-to-[to]` | 单位对页 ×~500 | "cm to inches" 类大词 |
| `/convert/[value]-[from]-to-[to]` | 数值页 ×~200 | "165 cm to inches" 高意图长尾 |
| `/category/[key]` | 类目枢纽 ×9 | 内链 |
| `/api/convert` | JSON(CORS 全开) | agent 数据口 |
